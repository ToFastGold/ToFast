# Архитектура Пятницы

## Схема

```
Омар (Telegram)
      |
      v
ПК с Windows: pc/jarvis_pc
  Telegram-бот (python-telegram-bot)
      |
      v
  OpenJarvis: агент orchestrator + инструменты
      |  модель: Claude (Anthropic API, ключ в .env)
      |
      +-- think, calculator, web_search (встроены в OpenJarvis)
      +-- phone_call, phone_sms, phone_open_app (наши, pc/jarvis_pc/phone_tools.py)
                 |
                 |  HTTP POST /command, заголовок Authorization: Bearer <токен>
                 v
Телефон Android: приложение-мост (android/, следующий этап)
  звонит, шлёт SMS, открывает приложения
```

## Почему так

OpenJarvis даёт готового агента с вызовом инструментов, поддержку Claude и кучу встроенных инструментов. Своих инструментов для телефона у него нет, поэтому мы дописываем три штуки и регистрируем их в его реестре (`ToolRegistry`). Код OpenJarvis не форкаем: он ставится из PyPI с закреплённой версией. Обновиться можно, поменяв версию в `pc/pyproject.toml`.

Telegram-бот написан у нас, а не взят из OpenJarvis, потому что нужен контроль над тем, кто может писать (только chat id Омара), и короткая история разговора.

Модель по умолчанию `claude-haiku-4-5`: дешёвая и быстрая, команд вроде "позвони маме" ей хватает. Запросы обрабатываются по одному, чтобы расход API был предсказуемым.

## Протокол моста (ПК -> телефон)

Телефон держит HTTP-сервер на порту 8765. ПК шлёт `POST {PHONE_BRIDGE_URL}/command` с JSON:

```json
{"action": "call", "target": "Мама"}
{"action": "sms", "target": "+15551234567", "text": "Буду в 7"}
{"action": "open_app", "app": "YouTube"}
```

`target` это номер или имя контакта: телефон сам ищет номер в контактах. Ответ: `{"ok": true, "message": "Звоню Мама (+1555...)"}` или `{"ok": false, "message": "Контакт не найден"}`. Без правильного токена телефон отвечает 401.

Телефон и ПК должны видеть друг друга: в одной Wi-Fi сети, а вне дома через Tailscale (бесплатно для личного использования).

## Этапы

1. Ядро на ПК: OpenJarvis + Claude + Telegram + инструменты телефона (этот PR).
2. Android-мост: Kotlin-приложение с HTTP-сервером, звонки через `ACTION_CALL`, SMS через `SmsManager`, запуск приложений через `PackageManager`. Работает как foreground service, чтобы Android его не убивал.
3. Голос: ответы голосом через ElevenLabs (голосовые сообщения в Telegram), распознавание голосовых через Whisper или ElevenLabs.
4. Twilio: звонки и SMS с отдельного номера, когда телефон недоступен, и возможность позвонить Пятнице. Каждый звонок и SMS через Twilio платный, поэтому включаем только после согласования.

## Деньги

Claude API: при Haiku один обычный запрос с инструментами стоит меньше цента. Twilio и ElevenLabs тратят деньги только на этапах 3 и 4, и подключать их будем только с согласия Омара.
