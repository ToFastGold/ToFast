# Цели: трекер на месяц с наградами

Ставишь цели на месяц, каждый день отмечаешь галочку, видишь процент выполнения. Если держишь общий процент не ниже порога (по умолчанию 70% и 80%), открывается награда, которую ты сам себе назначил. Пятница видит цели, может отметить их за тебя по сообщению в Telegram, вечером напоминает, что ещё не сделано, и в начале месяца пишет итог: заработал награду или нет.

## Как считается процент

Для каждой цели: отмеченные дни делить на учтённые дни. Учитываются дни с момента, когда цель добавлена, по вчерашний день, плюс сегодня, если уже отмечено. Поэтому утром, пока ничего не отмечено, процент не проседает. Общий процент: все отметки по всем целям делить на все учтённые дни. Прошлые дни можно отметить задним числом, нажав на клетку дня.

## Запуск на ПК (Windows)

Нужен Python 3.11 или новее. Сторонних библиотек нет.

```powershell
cd goals
copy .env.example .env
notepad .env
py -3.12 -m goals_app
```

В `.env` впиши `GOALS_API_TOKEN` (любая длинная случайная строка). Если `pc/.env` Пятницы уже заполнен, трекер сам возьмёт оттуда Telegram-бота и chat id, а `GOALS_API_TOKEN` можно вписать только туда, и тогда `goals/.env` не нужен.

В консоли появится адрес вида `http://192.168.1.23:8787`.

## На телефоне

1. Телефон в той же Wi-Fi сети, что и компьютер. Открой этот адрес в Chrome.
2. Введи токен. Телефон его запомнит.
3. Меню Chrome, "Добавить на главный экран". Появится иконка "Цели", открывается как обычное приложение.

Вне дома: поставь Tailscale (бесплатно) на ПК и телефон и открывай `http://<имя-пк>:8787`. Тот же способ нужен Android-мосту Пятницы, так что настраивается один раз. Windows может спросить про брандмауэр при первом запуске: разреши доступ для частных сетей.

## Связь с Пятницей

Пятница (`pc/jarvis_pc/goals_tools.py`) ходит в API по адресу `GOALS_API_URL` с тем же `GOALS_API_TOKEN`. Можно писать ей "отметь спорт", "как у меня с целями", "что я заработал".

Напоминания шлёт сам трекер через того же Telegram-бота (только отправка сообщений, бот Пятницы при этом работает как обычно):

- вечером в `GOALS_REMIND_AT` (по умолчанию 21:00): что сегодня не отмечено и сколько до награды;
- сразу, когда отметка открывает награду или она закрывается из-за пропусков;
- в первый день месяца: итог прошлого месяца и заработанная награда.

## API

Все запросы с заголовком `Authorization: Bearer <GOALS_API_TOKEN>`. Месяц по умолчанию текущий, можно передать `?month=2026-11` или `"month"` в теле.

| Запрос | Что делает |
|---|---|
| `GET /api/summary` | проценты, цели, награды |
| `POST /api/checkin` `{"goal_id", "date"?, "done"?}` | отметить или снять отметку; `goal_id` может быть названием цели |
| `POST /api/goals` `{"title"}` | добавить цель |
| `POST /api/goals/delete` `{"goal_id"}` | удалить цель |
| `POST /api/goals/copy` | перенести цели с прошлого месяца |
| `POST /api/rewards` `{"rewards": [{"percent", "text"}]}` | задать уровни наград |

Пример ответа `/api/summary`:

```json
{"month": "2026-11", "overall_percent": 72.4, "reward_unlocked": true,
 "reward": "Вечер игр без чувства вины", "next_reward": {"percent": 80, "text": "Покупка до 50$"},
 "days_left": 11, "goals": [{"id": "a1b2c3d4", "title": "Спорт", "percent": 79.0, "done_today": false}]}
```

Данные лежат в `goals/data/goals.json`. Этот файл стоит иногда копировать в облако на случай, если с диском что-то случится.
