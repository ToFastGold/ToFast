# ToFast

Alex Звонки: приложение для Android (PWA), в котором по одной кнопке ИИ-агент Alex (ElevenLabs) звонит клиенту, а итоги звонка приходят в отдельную вкладку.

- `docs/` приложение и страница заявки, публикуются через GitHub Pages (`/docs` на ветке `main`).
- `docs/request/` страница «Alex перезвонит» на английском с галочкой согласия.
- `backend/Code.gs` сервер на Google Apps Script внутри таблицы «Alex — заявки».
- `SETUP-RU.md` пошаговая установка.

Звонки идут только клиентам с записанным согласием, в разрешённые часы, с учётом списка «не звонить» (правила CRTC о звонках с ИИ-голосом).
